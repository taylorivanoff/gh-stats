Welcome to GhStats

Your local GitHub portfolio command center — stars, downloads, traffic, and release health.

  1. GitHub CLI — Install and sign in with gh
  2. Refresh — Pull stars, downloads, traffic, and health from GitHub
  3. History — Star timelines backfill from stargazer timestamps

Charts stay empty until a real fetch succeeds. GitHub only keeps traffic for 14 days; daily Refresh (or the Action) preserves it locally.
